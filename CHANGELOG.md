# Changelog

All notable user-facing and security changes to Kavrix are recorded per
release in [`docs/release-notes-*.md`](docs/README.md), indexed by the
[documentation index](docs/README.md). The current version is
[`apps/cli/package.json`](apps/cli/package.json).

Entries for releases up to and including 0.2.9 are preserved in the git
history of this file. This pointer replaces a hand-maintained ledger that
had drifted from the actual release notes.
